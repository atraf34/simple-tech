# SiMPLE TECHNOLOGIES — সম্পূর্ণ ই-কমার্স সাইট

Next.js 14 + Tailwind + Supabase। ফ্রি টিয়ারে (GitHub + Supabase + Vercel Hobby) চলে।

**যা আছে:** হোমপেজ · ক্যাটালগ (ভোল্টেজ/বাস/স্টক ফিল্টার) · প্রোডাক্ট পেজ (গ্যালারি, স্পেক, পিনআউট,
YouTube ভিডিও, বান্ডেল ক্যালকুলেটর) · কার্ট · ৩-ধাপ চেকআউট (bKash/Nagad/Rocket/COD) ·
মোবাইল-নম্বর দিয়ে গ্রাহক লগইন (অর্ডার হিস্ট্রি + ওয়ারেন্টি ডকুমেন্ট) · হিডেন অ্যাডমিন প্যানেল
(অর্ডার, ক্লায়েন্ট সার্চ, প্রোডাক্ট, ব্যানার/অফার টেক্সট, ওয়ারেন্টি আপলোড)।

## ডিপ্লয় — ৪টা ধাপ

### ধাপ ১ — GitHub
> ⚠️ জিপ ফাইলটা নিজে আপলোড করবেন না — আগে Extract করুন, তারপর ভেতরের **ফাইলগুলো** আপলোড করুন
> (`package.json` যেন রিপোর একদম উপরে থাকে, কোনো ফোল্ডারের ভেতরে না)।

1. github.com → New repository (যেমন `simple-technologies`)
2. "uploading an existing file" লিংকে ক্লিক → Extract করা সব ফাইল/ফোল্ডার ড্র্যাগ করে ছাড়ুন → Commit

### ধাপ ২ — Supabase
1. supabase.com → New project (ফ্রি) → পাসওয়ার্ড দিন, রিজিয়ন **Singapore** বেছে নিন
2. বাম মেনু **SQL Editor** → New query → `supabase/schema.sql` ফাইলের পুরো লেখা পেস্ট → **Run**
   (টেবিল, সিকিউরিটি, স্টোরেজ বাকেট ও স্যাম্পল প্রোডাক্ট সব একবারে তৈরি হবে)
3. **Authentication → Providers → Email** → **"Confirm email" বন্ধ (OFF)** করুন
   (গ্রাহকরা মোবাইল নম্বর দিয়ে সাইনআপ করে; নম্বর থেকে একটা ইন্টারনাল ইমেইল বানানো হয়)
4. **Project Settings → API** থেকে ৩টা জিনিস কপি করুন: `Project URL`, `anon public` key, `service_role` key

### ধাপ ৩ — Vercel
1. vercel.com → GitHub দিয়ে সাইন ইন → **Add New → Project** → আপনার রিপো Import
2. **Environment Variables** এ এই ৫টা যোগ করুন (`.env.example` দেখুন):

| Name | Value |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon public key |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role key (**গোপন**) |
| `ADMIN_SESSION_SECRET` | যেকোনো ৩২+ অক্ষরের র‍্যান্ডম লেখা |
| `ADMIN_SETUP_KEY` | আপনার নিজের বানানো গোপন কোড |

3. **Deploy** চাপুন → ১-২ মিনিটে সাইট লাইভ 🎉

### ধাপ ৪ — প্রথম অ্যাডমিন তৈরি (একবারই)
1. `https://আপনার-সাইট.vercel.app/vercel/203695/209/admin/setup` এ যান
2. আপনার মোবাইল নম্বর + পাসওয়ার্ড (৮+ অক্ষর) + `ADMIN_SETUP_KEY` দিন
3. এরপর `/vercel/203695/209/admin/login` দিয়ে লগইন করুন। অ্যাডমিন তৈরি হয়ে গেলে setup পেজ আর কাজ করে না।

**অ্যাডমিন লিংক (`/vercel/203695/209/admin`) কোথাও পাবলিকলি দেবেন না।** সার্চ ইঞ্জিনে ইনডেক্স হয় না।
লিংক বদলাতে চাইলে `app/vercel/203695/209/admin` ফোল্ডারের নাম, `lib/admin-config.ts` এবং `middleware.ts`-এর matcher — এই তিন জায়গায় একই নতুন পথ বসান।

## অ্যাডমিন প্যানেলে যা করতে পারবেন
- **অর্ডার:** ফোন/নাম/অর্ডার নম্বরে সার্চ, স্ট্যাটাস বদলানো, ইন্টারনাল নোট
- **ক্লায়েন্ট:** ফোন বা নামে সার্চ → তার সব অর্ডার, নোট ও ওয়ারেন্টি ডকুমেন্ট
- **প্রোডাক্ট:** নতুন প্রোডাক্ট + ছবি আপলোড, দাম, স্টক, ফ্ল্যাশ ডিল, **YouTube ভিডিও লিংক**
- **কনটেন্ট:** হিরো ব্যানারের লেখা, স্ক্রলিং অফার টেক্সট (হোমপেজে সাথে সাথে বদলায়)
- **ওয়ারেন্টি:** অর্ডার নম্বর দিয়ে ফাইল আপলোড → গ্রাহক নিজের অ্যাকাউন্টে দেখতে পান

## কুপন কোড
`lib/pricing.ts` এ: `WELCOME10` (১০%), `ROBOTECH50` (৳৫০ ছাড়)। নতুন কোড এখানেই যোগ করুন।

## লোকালি চালাতে
```bash
cp .env.example .env.local   # মান বসান
npm install && npm run dev
```
Supabase কী ছাড়াও সাইট চলে (ডেমো ডেটা দিয়ে, অর্ডার সেভ হয় না)।

## জেনে রাখুন
- **পেমেন্ট:** bKash/Nagad/Rocket এখন শুধু "পছন্দ" হিসেবে অর্ডারে সেভ হয়; টাকা অটো কাটে না।
  আপনার টিম অর্ডার দেখে গ্রাহককে নম্বর জানিয়ে কনফার্ম করবে। অটো পেমেন্টের জন্য পরে
  bKash/SSLCommerz মার্চেন্ট API লাগবে।
- **AI চ্যাট:** এখনো বানানো হয়নি (পরবর্তী ধাপ)।
- **Supabase ফ্রি টিয়ার:** এক সপ্তাহ কেউ না ঢুকলে প্রজেক্ট পজ হয়ে যেতে পারে; ড্যাশবোর্ড থেকে Resume করা যায়।
